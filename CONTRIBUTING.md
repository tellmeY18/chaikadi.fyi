# Contributing to Chaikadi

Splitting a group order is a problem almost everyone has had and nobody has
fixed well. Chaikadi is free, open source (AGPL-3.0), has no ads, accounts or
tracking, and it belongs to everyone who uses it. It only gets good with
collective help, and yours counts.

## Ways to help

- **Report a bug.** [Open an issue](https://github.com/tellmeY18/chaikadi.fyi/issues/new?template=bug_report.yml).
  What you saw and your phone and browser is plenty.
- **Send a patch.** Fork, change, open a pull request. Small fixes are as
  welcome as big ones. Look for issues labelled `good first issue`.
- **Suggest an idea.** [Tell us](https://github.com/tellmeY18/chaikadi.fyi/issues/new?template=idea.yml)
  what your group runs into.
- **Add menus and prices.** Menu data lives in [Eatsights](https://github.com/tellmeY18/eatsights).
- **Spread the word.** Star the repo and share it with your group.

## Set up

There is no build step. See "Run locally" in the [README](README.md), then:

```sh
npm test
```

Please run the tests and keep changes focused. By contributing you agree your
work is released under AGPL-3.0.
